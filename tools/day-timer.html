Day Timer

Plan the day for each child: add a name and date, then add each subject as a countdown timer (a set number of minutes) or a stopwatch (counts up, for work with no fixed length). Each child has their own list, but only one timer runs at a time: starting another one pauses the first. Export the day as a printable sheet, text, or CSV.
